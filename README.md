# GitHub Pages starter

1. Create a repository named `YOUR_GITHUB_USERNAME.github.io`.
2. Upload the contents of this folder to the repository root.
3. In GitHub: Settings → Pages → Deploy from a branch → main → /(root).
4. Your site will appear at `https://YOUR_GITHUB_USERNAME.github.io`.

## Add your profile photo
Put a square photo at `assets/profile.jpg`, then change `assets/profile-placeholder.svg` to `assets/profile.jpg` in `index.html`.

## Resume
`resume.pdf` is included from your current resume. Replace it whenever you update your resume.
